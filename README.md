# LARE Prep

Comprehensive study materials and interactive practice exams for all four sections of the **Landscape Architect Registration Examination (LARE)**, styled with the ASLA design system.

## Sections

| Section | Title | Scored Items |
|---------|-------|-------------|
| 1 | Project Management and Professional Practice | 75 |
| 2 | Planning and Design | 85 |
| 3 | Construction Documentation and Administration | 90 |
| 4 | Grading, Drainage, and Stormwater Management | 70 |

## Features

- **Study Guides** — concise outlines with key concepts, reference tables, and exam strategies
- **Study Books** — full textbook narratives with exam tips, memory aids, and real-world examples
- **Practice Exams** — 40 interactive multiple-choice questions per section with instant scoring and explanations
- **Progress Tracking** — localStorage-persisted best scores and attempt counts
- **Responsive Design** — works on desktop, tablet, and mobile

## Design

Built with the ASLA (American Society of Landscape Architects) design system:

- **Typography**: Retina (sans), Skolar Latin (serif), JetBrains Mono
- **Colors**: ASLA Teal `#003A49`, ASLA Green `#81BC00`, Warm Cream `#F4F2ED`
- **Components**: mixed-radius image treatments, pill buttons, subtle shadows

## Deployment

This is a static site — no build step required. Deploy to GitHub Pages, Netlify, or any static host by pointing to the root directory.

To run locally:

```bash
npx serve .
```
